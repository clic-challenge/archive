CLIC 2018 datasets

The first ever Challenge on Learned Image Compression introduced two image datasets: one for mobile and one for professional photography. The training and validation sets were reused in 2019 and 2020, and have often been referred to as part of the CLIC 2020 datasets. The test sets for this year have unfortunately not been preserved.

  • Mobile training set (3.8 GiB, same as CLIC 2020)
  • Mobile validation set (226 MiB, same as CLIC 2020)
  • Mobile test set (unavailable)
  • Professional training set (1.9 GiB, same as CLIC 2020)
  • Professional validation set (129 MiB, same as CLIC 2020)
  • Professional test set (unavailable)
CLIC 2019 datasets

In the second Challenge, new test sets were introduced, but the other datasets were re-used from 2018.

  • Mobile training set (3.8 GiB, same as CLIC 2020)
  • Mobile validation set (226 MiB, same as CLIC 2020)
  • Mobile test set (355 MiB)
  • Professional training set (1.9 GiB, same as CLIC 2020)
  • Professional validation set (129 MiB, same as CLIC 2020)
  • Professional test set (833 MiB)
CLIC 2020 datasets

The third Challenge again introduced new test sets, with the other datasets re-used from the previous year. In addition, the challenge featured a P-frame compression challenge, whose datasets have unfortunately not been preserved.

  • Mobile training set (3.8 GiB)
  • Mobile validation set (226 MiB)
  • Mobile test set (689 MiB)
  • Professional training set (1.9 GiB)
  • Professional validation set (129 MiB)
  • Professional test set (851 MiB)
CLIC 2021 datasets

The fourth Challenge introduced a video track based on the UGC dataset, and a perceptual track based on similarity of image crops. The image track focused only on professional photography this year.

  • Image training set (1.9 GiB, same as CLIC 2020 professional)
  • Image validation set (129 MiB, same as CLIC 2020 professional)
  • Image test set (204 MiB)
  • Video dataset: refer to the tasks page of the CLIC 2021 website.
  • Perceptual validation set, image crops (2.2 GiB)
  • Perceptual validation set, ratings (244 KiB)
  • Perceptual test set, image crops (47 GiB)
  • Perceptual test set, ratings (3.2 MiB)
CLIC 2022 datasets

The fifth Challenge continued image, video, and perceptual tracks. It also introduced its own video dataset, with a full validation set consisting of nearly 300 videos, and a subset of 30 videos used during the validation phase. The image track again focused only on professional photography this year.

  • Image validation set (121 MiB)
  • Image test set (130 MiB)
  • Video full validation set (2.2 GiB)
  • Video validation set (367 MiB)
  • Video test set (180 MiB)
  • Perceptual validation set, image crops (2.2 GiB, same as CLIC 2021)
  • Perceptual validation set, ratings (244 KiB, same as CLIC 2021)
  • Perceptual test set, image crops (135 GiB)
  • Perceptual test set, ratings (13 MiB)
CLIC 2024 datasets

The sixth Challenge introduced new test sets for both compression tracks, and also added a video perceptual track. The image datasets were augmented with a small number of screen and gaming images.

  • Image validation set (130 MiB, same as CLIC 2022 test set)
  • Image test set (102 MiB)
  • Video full validation set (2.2 GiB, same as CLIC 2022)
  • Video validation set (367 MiB, same as CLIC 2022)
  • Video test set (300 MiB)
  • Perceptual image validation set, image crops (2.2 GiB, same as CLIC 2021)
  • Perceptual image validation set, ratings (244 KiB, same as CLIC 2021)
  • Perceptual image test set, image crops (46 GiB)
  • Perceptual image test set, ratings (5.9 MiB)
  • Perceptual video validation set, originals (180 MiB, same as CLIC 2022 video test set)
  • Perceptual video validation set, reconstructions (7.3 GiB)
  • Perceptual video validation set, mean opinion scores (8 KiB)
  • Perceptual video test set, originals (300 MiB, same as video test set)
  • Perceptual video test set, reconstructions (44 GiB)
  • Perceptual video test set, mean opinion scores (8 KiB)
CLIC 2025 datasets

The seventh Challenge discontinued the perceptual tracks. Also, some raw sequences were added to the video datasets.

  • Image validation set (102 MiB, same as CLIC 2024 test set)
  • Image test set (116 MiB)
  • Video validation set (2.8 GiB, contains some sequences from the CLIC 2024 video test set)
  • Video test set (4.6 GiB)
